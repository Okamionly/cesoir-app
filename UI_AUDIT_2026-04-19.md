## Patterns récurrents

- **Floating C-bubble (☾)** présent sur quasi TOUTES les pages (15+) et **gêne systématiquement** un CTA bas. À retravailler/repositionner ou activer seulement sur certains contextes.
- **Bottom nav layout buggy** : sur 2-3 pages la nav apparaît inline au lieu de fixed. Vérifier le composant `<BottomNav>` et son wrapping (`md:hidden` + `position:fixed bottom-0` + `z-50`).
- **White-on-light contrast** systématique sur les pages à hero gradient (modes/[slug], safety SOS, FlashNote chat). Manque de garde-fou contraste WCAG AA.
- **Headers inconsistents** : certains ont juste un mini logo, d'autres un titre + actions. Définir une convention (PageHeader component avec props title/actions).
- **Empty states pas distincts du loading state** — pas de skeletons visibles, pas de "Aucun résultat" sur états vides.
- **401 Supabase errors omniprésents** sur /events, plusieurs autres pages — le hook auth client est en défaut. Probablement à fixer dans le supabase client init.
- **Bottom safe-area** : padding-bottom manquant sur plusieurs scrollable areas → contenu caché derrière la bottom nav fixe (Mocktails, Rejoindre, etc.).

## Cohérence design system

- **Typography** : ❌ inconsistante. Card titles vary in size on /modes, /safety. Body grey-300 too pale, illisible sur fond blanc clair.
- **Spacing** : ❌ trop de gaps géants sur /modes (cards éloignées ~120px sans raison). Padding bottom manquant pour bottom nav.
- **Couleurs** : 🟡 White Fluo Minimal palette respectée sur les pages "polishées" (feed/browse/profile/notifications) — bien. Mais hero gradients pages-modes utilisent des purples trop pâles qui cassent le contraste blanc.
- **Motion** : 🟡 Polish Hollywood clairement visible sur /feed et /browse (cards entrent fluide). PAS visible sur /modes, /events, /soiree (statiques au load). Inconsistance.
- **Bottom nav** : ❌ comportement non-déterministe (parfois fixed, parfois inline).
- **Floating FAB** : ❌ omniprésent, casse l'UX mobile.

## Top 10 fixes prioritaires (par ordre)

1. **Fixer la bottom nav** : composant `<BottomNav>` doit être `md:hidden + fixed bottom-0 z-50`. Vérifier qu'il n'est rendu qu'une fois (pas dans chaque page).
2. **Repositionner ou supprimer le C-bubble (☾)** sur les pages où il bouffe les CTA (mobile au moins). Décaler en `bottom-20 right-4` minimum (au-dessus de la bottom nav).
3. **Fixer le contraste white-on-light sur /modes/[slug]** : foncer les titres ou intensifier le gradient hero. Audit WCAG complet sur les pages mode-detail.
4. **Fixer la hydration error EventCard** : refactor le `Link` "Carte" pour qu'il ne soit pas dans le `Link` principal de la card. Soit `<button onClick={navigate}>`, soit séparer les zones cliquables.
5. **Fixer les 401 Supabase** sur /events et autres : vérifier le supabase client (cookies/JWT pas envoyés ?). Ces erreurs cachent des bugs de données silencieux.
6. **Fixer /map** : la carte n'est rendue qu'à moitié sur desktop, et les bottom cards se chevauchent. Audit du carrousel + map container.
7. **Header consistency** : créer un `<PageHeader>` réutilisable avec `title` + `actions` props. Appliquer partout.
8. **Padding-bottom safe-area** : ajouter `pb-24 md:pb-0` sur les `<main>` scrollables (ou utiliser `safe-area-inset-bottom`) pour que le contenu ne se cache pas derrière la nav.
9. **/discover mobile** : restaurer le header (titre + filter) caché sur mobile.
10. **Polish manquant sur /events, /soiree, /modes** : ajouter le motion polish déjà appliqué sur /feed et /browse (entrance animations, hover states, skeletons).
