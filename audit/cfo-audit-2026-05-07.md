## Red Flags

1. **Stripe désactivé en prod.** Aujourd'hui, si un user clique "Subscribe", il reçoit une erreur 400. C'est le red flag #1 — chaque jour sans revenus potentiels est du feedback produit perdu.

2. **Zéro métriques de traction.** PostHog est installé mais non instrumenté sur les events business. Un investisseur pré-seed demande : combien de matchs par jour ? Quel % ouvre le chat ? Quel % hit le paywall ? Réponse actuelle : inconnue.

3. **TVA FR non provisionnée.** Toute transaction B2C en France est assujettie à TVA 20%. Sans Stripe Tax activé, les premiers euros encaissés créent un passif fiscal immédiat.

---

## 3 Recommandations financières prioritaires

### 1. Activer Stripe en test cette semaine (priorité absolue)

Exécuter `STRIPE_SECRET_KEY=sk_test_xxx npx tsx scripts/setup-stripe-products.ts`, coller les `price_xxx` dans Vercel, activer Stripe Tax mode automatique EU. Objectif : premier paiement test réel avant M+7 jours. Cela débloque la boucle feedback prix/valeur et valide le pipe technique end-to-end avant les premiers vrais users.

### 2. Instrumenter 5 events PostHog avant le lancement beta

Les 5 events non-négociables : `user_signup`, `first_swipe`, `first_match`, `paywall_view`, `subscription_started`. Sans ces données, impossible de calculer un funnel de conversion, impossible de justifier un CAC cible, impossible de pitcher un investisseur. Budget temps : 2 heures de dev. Retour sur investissement : data room complète à M6.

### 3. Réviser le pricing annuel de -50% à -33%

Passer le Premium Annuel de 59.99€ à 79.99€ (6.67€/mois). La réduction actuelle de 50% est trop généreuse sans preuve de rétention à 12 mois dans le dating. Le différentiel reste attractif (33% vs mensuel) et augmente le ARPU moyen de ~12% sur les annuels. Si le churn réel est meilleur qu'attendu, vous pourrez toujours baisser le prix — l'inverse est impossible sans friction utilisateur.
