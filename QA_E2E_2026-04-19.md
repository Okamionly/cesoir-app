## Bugs prioritaires

### 🔴 P0 (bloquant)
1. **`/chat` crash en error boundary** — `useConversations` essaie d'ajouter un callback `postgres_changes` à un channel Supabase Realtime déjà subscribed. La page chat est totalement inutilisable. Origin : `<BottomNav>` ou `useConversations` hook ne nettoie pas correctement le channel entre re-renders. À fixer en appelant `.on()` AVANT `.subscribe()` ou en re-créant le channel.
2. **`update_location` RPC manquante** — 404 sur tous les loads `/feed`, `/browse`, `/discover`. Soit la migration Supabase n'est pas appliquée, soit le nom de la fonction côté client diffère.
3. **`nearby_profiles` RPC ambiguous** — 2 overloads (avec/sans `age_min/age_max`). Le client appelle sans préciser → Postgres ne sait pas choisir → 300. Solution : drop l'ancienne signature ou passer explicitement les 2 args (même `null`).

### 🟠 P1 (haute prio)
4. **Email rate limit Supabase** — Le projet `ycyxmvzilzkusecpgvbi` a atteint sa quota d'envoi confirmation. Tout signup via UI est cassé pour les nouveaux utilisateurs. Actions : passer Supabase en plan paid OU configurer un SMTP custom (SendGrid/Resend) OU autoconfirm en dev avec `auth.email.enable_confirmations=false`.
5. **Email TLD `.local` rejeté** — Le brief demandait des emails `@cesoir-test.local` mais Supabase auth les rejette. Bug ou design? À documenter pour le futur QA.
6. **Splash "Nouveau jour" sans dismiss** — Sur `/browse` la modale recouvre tout sans bouton clair pour fermer (a fallu JS hack). Auto-dismiss prévu après ~3s ne fonctionne pas systématiquement.
7. **`/about` montre BottomNav** — Régression Sprint 1+2. Pages publiques doivent cacher le BottomNav.

### 🟡 P2 (moyen)
8. **Map tiles maplibre vides** — Fond noir uni sur `/map`. Style URL probablement non configuré pour env local.
9. **Contraste insuffisant sur `/modes/[mode]`** — Le hero pastel violet-blanc avec texte gris clair viole WCAG AA. Le titre principal est presque invisible.
10. **`manifest.webmanifest` syntax error** — Émis sur toutes les pages. Le fichier doit avoir un BOM ou un caractère invalide en entête.
