# Venues Targets — 10 bars Montpellier prioritaires Wave 1

Shortlist de 10 venues à contacter en premier pour le lancement Wave 15 CeSoir.
Critères de sélection :

1. **Audience Gen Z active** (18-30 ans)
2. **Programmation régulière** (au moins 2 soirées/semaine)
3. **Instagram actif** (5k+ abonnés, > 1 post/semaine)
4. **Localisation** Montpellier centre ou zones à fort trafic
5. **Positioning** aligné CeSoir (pas bar à vieux, pas uniquement touristique)

---

## Top 10 prioritaires

### 1. Rockstore
- **Adresse** : 20 Rue de Verdun, 34000 Montpellier
- **Style** : Rock / indie / live music, salle de concert + bar
- **Audience** : 22-35 ans, étudiants + jeunes actifs rock-alternatif
- **Instagram** : `@rockstoremtp` (suivi à vérifier)
- **Pourquoi pertinent** : institution Montpellier, lineup régulier,
  compatibilité totale avec la rubrique Soirées CeSoir
- **Formule suggérée** : 490€/mois Featured permanent (value max)
- **Contact à trouver** : responsable communication / programmation

### 2. L'Antirouille
- **Adresse** : 12 Rue d'Alger, 34000 Montpellier
- **Style** : Club / techno / hip-hop underground
- **Audience** : 20-30 ans, gen Z + jeunes actifs, clubbing
- **Instagram** : `@antirouille` (à confirmer)
- **Pourquoi pertinent** : la scène techno de Montpellier passe par ici,
  audience ultra-ciblée sorties tardives
- **Formule suggérée** : 149€/semaine Featured sur 4 semaines
- **Contact à trouver** : résident / programmateur

### 3. Panama
- **Adresse** : Plan du Cabane (à vérifier), Montpellier
- **Style** : Bar rooftop / cocktails / apero afterwork
- **Audience** : 25-35 ans, jeunes actifs, soirées afterwork
- **Instagram** : `@panamamontpellier` (à confirmer)
- **Pourquoi pertinent** : rooftop bankable, audience bien habillée,
  Instagram ready
- **Formule suggérée** : 49€/soirée pour les soirées thématiques

### 4. Black Sheep
- **Adresse** : 2 Rue Saint-Paul, 34000 Montpellier
- **Style** : Pub / craft beer / quiz / concerts intimistes
- **Audience** : 22-30 ans, étudiants Erasmus, expats
- **Instagram** : `@blacksheepmtp` (à confirmer)
- **Pourquoi pertinent** : audience internationale, intéressante pour le
  mode "Langue" de CeSoir
- **Formule suggérée** : 49€/soirée + parrainage Langue mode

### 5. Le Dôme
- **Adresse** : Esplanade Charles-de-Gaulle, 34000 Montpellier
- **Style** : Bar central / rooftop / terrasse
- **Audience** : 25-35 ans, jeunes actifs, touristes, mix local/visiteurs
- **Instagram** : `@ledomemontpellier` (à confirmer)
- **Pourquoi pertinent** : positionnement central, vue sur l'Esplanade,
  touch touristique utile pour mode Tourist
- **Formule suggérée** : 149€/mois Featured medium

### 6. La Barbote
- **Adresse** : Halles Laissac / Comédie (à confirmer)
- **Style** : Bar apéro / café / coworking évening
- **Audience** : 23-30 ans, créatifs, étudiants en master, indépendants
- **Instagram** : `@labarbote` (à confirmer)
- **Pourquoi pertinent** : audience "slow bar", vibe conversation, parfait
  pour le mode Solo Dîner et Plus One
- **Formule suggérée** : 49€/soirée ponctuel, upsell sur mode spécifique

### 7. Secret Place
- **Adresse** : Route de Lavérune, Saint-Jean-de-Védas (périphérie)
- **Style** : Club techno/house/drum'n'bass
- **Audience** : 20-30 ans, clubbing hardcore, scène électronique avancée
- **Instagram** : `@secretplacemtp` (à confirmer)
- **Pourquoi pertinent** : référence techno régionale, soirées à forte
  affluence, compatibilité CeSoir perfecte
- **Formule suggérée** : 149€/semaine pour les week-ends événementiels

### 8. Les Berges du Lez
- **Adresse** : Le long du Lez, côté quartier Port Marianne
- **Style** : Bar éphémère été / guinguette / concerts open air
- **Audience** : 25-40 ans, mix familial et sortie, pic en été
- **Instagram** : `@bergesdulez` (à confirmer)
- **Pourquoi pertinent** : contenu visuel fort, Instagram-friendly, audience
  large pour mode Plus One et Tourist été
- **Formule suggérée** : 490€/saison été (mai-sept)

### 9. Le Corum (zone évènements)
- **Adresse** : Esplanade Charles-de-Gaulle, 34000 Montpellier
- **Style** : Palais des congrès, évènements culturels + concerts
- **Audience** : 25-45 ans, culturelle mixte
- **Instagram** : `@corum_montpellier` (à confirmer)
- **Pourquoi pertinent** : événements à forte valeur, partenariat B2B
  institutional, ouvre sur les modes Tourist et Langue
- **Formule suggérée** : Partenariat annuel bilatéral, barter à définir

### 10. Zone Comédie (plusieurs cafés/bars)
- **Adresse** : Place de la Comédie, 34000 Montpellier
- **Style** : Multi-venues, terrasses café, apéros
- **Audience** : Toutes, très mainstream
- **Instagram** : multiples comptes
- **Pourquoi pertinent** : densité du trafic, visibilité passing-by
- **Formule suggérée** : packages groupés avec 3-4 terrasses pour
  événements "apero Comédie" co-brandés CeSoir
- **Contact** : chambre de commerce Montpellier ou approche individuelle
