# CeSoir — Press Kit

*Dernière mise à jour : 23 avril 2026 · Wave 15 (CRO 10/10)*

## Qu'est-ce que CeSoir ?

**CeSoir** est la première app de rencontre "ce soir" en France. On a supprimé les
paywalls, on a mis la ville au centre, et on oriente vers les bars partenaires
plutôt que vers les abonnements premium. Lancement beachhead : **Montpellier**.

Baseline : _"14 modes de rencontre. Zéro paywall. Ce soir."_
