> *« Un pipeline organisé = des hires rapides = une boîte qui avance. »*

Ce doc est un **kanban markdown** pour tracker les candidats en cours. Le founder remplit au fil de l'eau — chaque candidat = 1 bullet sous la colonne correspondante.

## Légende

| Colonne | Signification |
|---|---|
| **Applied** | Candidat a postulé, pas encore contacté |
| **Screen** | 1er call découverte en cours ou done |
| **Test** | Test case / test technique en cours |
| **Interview** | Entretien approfondi (tech pairing, culture call) |
| **Offer** | Offre envoyée, en négociation |
| **Hired** | Contrat signé, onboarding lancé |
| **Rejected** | Process terminé, pas retenu (on note pourquoi pour mémo) |
| **Withdrew** | Candidat s'est retiré |

## Template bullet (à copier-coller)

Pour chaque candidat, utiliser ce format :

```markdown
- **[Prénom Nom]** — [Source] — [Date applied]
  - Profil : [1 ligne résumé profil]
  - Statut : [date + statut actuel]
  - Prochaine action : [action + deadline]
  - Notes : [key insights, red flags, strengths]
  - Docs : [lien CV, portfolio, test case]
```

### Exemple

```markdown
- **Sophie Martin** — Welcome to the Jungle — 2026-05-02
  - Profil : ex-Bumble product designer, 6 ans XP, basée Lyon
  - Statut : 2026-05-10, test case rendu et reviewé (excellent)
  - Prochaine action : offer envoyée 2026-05-12, attendre réponse
  - Notes : très alignée values, pushback intelligent sur safety flow, bonus MTP origin (famille)
  - Docs : [CV](https://notion.so/xxx), [portfolio](https://sophie.design), [test](https://figma.com/xxx)
```

## Protocole de rejection respectueuse

Quand on rejette un candidat :
1. **Toujours répondre** (pas de ghosting, même sur 100 candidatures).
2. **Feedback bref mais honnête** : 2-3 lignes sur ce qui n'a pas matché.
3. **Garder contact** si profil intéressant mais timing mauvais : "On revient vers vous Q3 quand on recrute un senior CDI".
4. **Pas de faux espoir** : si c'est non, c'est non.

### Template email rejection

```
Bonjour [Prénom],

Merci pour ton investissement dans notre process [designer/tech lead/etc.].

Après réflexion, on ne va pas avancer avec toi sur ce rôle spécifique. La raison principale : [raison honnête, 2-3 lignes — ex: "on cherchait plus de XP sur safety UX female-first" ou "ton approche est solide mais on a trouvé un profil plus aligné sur notre vision produit"].

[Optionnel] Ton profil pourrait être pertinent pour un rôle [X] qu'on ouvrira [timing]. Si intéressant.e, on te recontacte à ce moment.

Merci encore, et bonne continuation.

— [Founder]
CeSoir
```
