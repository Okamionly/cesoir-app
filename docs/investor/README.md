## Contexte

**CeSoir** est une app de rencontre sociale **gratuite utilisateur, payante venue** —
modèle "marketplace inversé" : au lieu de vendre la rencontre au user (comme
Tinder), on vend la fréquentation aux lieux de sortie (bars, clubs, events).

- **Launch** : Montpellier, mai 2026.
- **Stack** : Next.js 16 + Supabase + Vercel (hébergement UE).
- **Stage** : pré-seed, auto-financé, 0 € levé à date.
- **Roadmap monétisation** : novembre 2026 (M+6).
